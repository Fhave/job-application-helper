# Job Application Helper

An AI-powered web application designed to help job seekers generate tailored resumes and instant cover letters optimized for ATS and recruiters.

---

## Features

- **Step-by-Step Resume Builder:** Intuitive, guided workflow to build professional resumes section by section.
- **AI-Powered Writing & Fixes:** Smart phrasing suggestions and automatic error corrections.
- **Job Description Tailoring:** Paste any job posting to automatically match your application content to key recruiter requirements.
- **Instant Cover Letter Generator:** Generate tailored cover letters in under two minutes based on your resume and target role.

---

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
- **Code Quality:** ESLint & Prettier
